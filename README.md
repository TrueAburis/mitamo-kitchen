# mitamo-kitchen

みたもっちゃんねる 公式サイト（制作中）

出汁からはじめる和食のレシピを、日本語と英語で載せています。
**作っている最中に分量が画面から消えないこと**を、このサイトの中心に置いています。

## 中身

日本語（`/`）と英語（`/en/`）で、同じ構成のページを別々のURLに置いています。

| ページ | 内容 |
|---|---|
| トップ | 名乗り・SNS・人気のレシピ・プロフィール |
| レシピ一覧 | 検索、タグ絞り込み（食材／料理の形／場面／時間）、並び替え |
| 献立 | レシピを束ねて、その日の食卓が決まるようにしたもの |
| レシピガチャ | 今日なにを作るか決まらないときに引く |
| レシピ詳細 | 手順を読んでいる間、分量が画面から消えない（17件） |
| お仕事のご依頼 | Google フォーム |

## 作り

素の HTML・CSS・JavaScript を書き出す形です。閲覧側にフレームワークは入っていません。

書くものと、書き出されるものを分けています。

| | |
|---|---|
| `data/` `content/` | レシピ・献立・対訳などの元データ（手で書く） |
| `assets/` | CSS・JS・写真（加工せずそのまま配る） |
| `tools/` | 組み立てと検証（TypeScript） |
| `infra/` | 公開先の定義（AWS CDK） |
| `dist/` | **書き出されるもの。ここを丸ごと公開します**（git では追っていません） |

- ページは `npm run build` で `dist/` に組み立てます（HTMLは直接編集しません）
- 組み立てと検証の道具は TypeScript。Node が型を直接実行するので、変換の段階はありません
- 外部から読み込むのは、見出しの書体・お仕事のご依頼フォーム・レシピ動画の3つだけ。
  **フォームと動画は、押されるまで読み込みません**

### 手元で動かす

```bash
npm install
npm run build
powershell -ExecutionPolicy Bypass -File serve.ps1
```

http://localhost:8000/ が開けるようになります（配るのは `dist/` の中身だけなので、
本番と同じものを見ることになります）。止めるときは Ctrl + C。

```bash
npm test        # キャプション解析と取り込みの検証
npm run check   # 型検査
```
